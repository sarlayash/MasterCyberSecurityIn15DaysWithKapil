## 📌 Executive Overview

**Cyber Security Zero-To-Infinity** is a corporate-grade, production-ready educational platform and virtual cyber range engineered to take learners from foundational principles to advanced cyber defense operations in a structured 15-day sequential journey.

### 🌟 Core Pillars
1. **Learn**: Deep conceptual mastery across 15 structured curriculum days.
2. **Practice**: 9 in-browser Virtual Cyber Labs (Command Prompt, Linux Terminal, Stateful Firewall Simulator, Wireshark Packet Inspector, SOC SIEM Triage, Incident Response Tree, Forensics Timeline).
3. **Question**: 100-Question Corporate Benchmark Assessment & Day-by-Day Mock Exams.
4. **Verify**: Strict 70% passing threshold for Level Badges, Assessment Badges, and Official Letter of Recommendation (LOR).
5. **Protect**: Threat Intelligence Bulletin Board analyzing 16 landmark cyber attacks (India & abroad) with avoidance blueprints.
6. **Share**: 1080×1080 high-res metallic badge generator with 1-click PNG export and printable executive LOR.

## 🔒 Security & Pedagogical Architecture

### 1. Verified Google Sign-In & Cloud Firestore
- **No Fake Accounts**: All learners authenticate using genuine Google accounts (`@gmail.com`).
- **Cloud Persistence**: Profiles, assessment attempts, and lab metrics sync to Google Cloud Firestore in real time.

### 2. Strict Day 1 Sequential Lock Engine
- Learners must begin at **Day 01**.
- Subsequent days (Days 02 to 15) remain securely padlocked until the preceding day's practical assignment or mock assessment is passed.
- Prevents skipping ahead and guarantees deep, cumulative learning.

### 3. Dual-Perspective Curriculum Notes
- **Student Life Analogy**: Relatable campus, hostel, exam, and daily life metaphors for every topic.
- **Real Industry Use Case**: Concrete production enterprise realities (AWS IAM, Cloudflare, CrowdStrike, PCI-DSS, SOC playbooks) for every topic.
- **Day Incident Case Study**: Landmark historical breach deconstructed for each day with root causes and avoidance blueprints.

### 4. Credentials & Certification Engine
- **Badges Engine**: Levels 1–10, Assessment Master ($\ge 70\%$), Milestone Master, and Lab Pioneer badges.
- **1080×1080 PNG Downloader**: HTML5 Canvas engine rendering cryptographic verification seals, learner names, and Kapil's signature.
- **Letter of Recommendation (LOR)**: Executive institutional letterhead with quantified competency appraisal, SarlaYash seal, and `@media print` PDF support.

## 🛠️ Local Development & Quickstart

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher)
- [npm](https://www.npmjs.com/) (v9.0.0 or higher)

### Installation
```bash
# Clone the repository
git clone https://github.com/sarlayash/MasterCyberSecurityIn15DaysWithKapil.git

# Navigate into project directory
cd MasterCyberSecurityIn15DaysWithKapil

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will be accessible at `http://localhost:5173/`.

### Production Build
```bash
# Compile TypeScript and bundle with Vite
npm run build

# Preview production build locally
npm run preview
```
